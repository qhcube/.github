# qhcube/.github

Ficheros comunes a todos los repositorios de la organización `qhcube`.

| Ruta | Qué es |
|---|---|
| `ISSUE_TEMPLATE/` | Formularios para crear issues (Bug, Funcionalidad, Tarea). Se aplican a todos los repos que no tengan los suyos. |
| `PULL_REQUEST_TEMPLATE.md` | Plantilla de descripción de los PRs. Ídem. |
| `docs/flujo-de-trabajo.md` | Cómo organizamos el trabajo: issues, Project, milestones, ramas, commits, releases. |
| `para-cada-repo/` | Ficheros que GitHub **no** hereda desde aquí y hay que copiar a cada repo, respetando la ruta (`para-cada-repo/.github/release.yml` → `<repo>/.github/release.yml`). |
